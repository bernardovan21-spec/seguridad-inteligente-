1. El primer guardián de tu casa — el sensor de movimiento (publicado)
2. El portón que se abre desde tu celular — el controlador inteligente (publicado)

## Reglas del proyecto

- Sin prometer seguridad absoluta.
- Las plataformas ejecutan reglas configuradas; no son cerebros con IA.
- Compatibilidad verificada antes de publicar; nada inventado.
